# PARALLAX v0.4 - Judge Verification Mode

PARALLAX v0.4 makes the public demonstration independently auditable without
requiring credentials, paid inference, or a local installation.

## What the browser verifies

For each experiment, the Control Deck downloads the original committed:

1. Nemotron experiment plan.
2. Nebius Sandbox execution evidence.
3. Assembled counterfactual proof.

The browser then uses the Web Crypto API to recompute all three SHA-256 hashes
and evaluates the proof contract from the raw artifacts:

- the selected intervention is Nemotron's top-ranked candidate;
- the planned capability is the capability Nebius executed;
- both branches reference the same checkpoint;
- the control branch passes the invariant;
- the counterfactual branch fails the invariant;
- the assembled proof retains the expected source hashes.

No API response or precomputed UI flag is trusted for the final verification
state. Any changed byte, intervention mismatch, checkpoint mismatch, or invalid
branch result makes verification fail closed.

## Scope

This release does not change the planner, experimental engine, frozen evidence,
or supported failure families. It is a presentation and verification release
designed to let a hackathon judge audit the existing claims in one click.
